# Password Strength Evaluation Report

## 1. Introduction

This report documents the evaluation of different sample passwords to understand how password length and complexity affect password security.

The passwords were created for educational purposes and evaluated using an online password strength checker.

> **Security Note:** Only fictional/test passwords should be used with online password-checking tools. Never enter a real personal password.

---

## 2. Objective

The main objectives of this task were:

* Understand the characteristics of a strong password.
* Create passwords with different levels of complexity.
* Evaluate password strength using an online tool.
* Understand how password length affects security.
* Learn about common password attacks.
* Identify best practices for creating secure passwords.

Several sample passwords with different levels of complexity were considered for evaluation.

| Password Type | Example             | Complexity                              |

## 4. Password Strength Analysis

### Very Weak Password

**Example:** `123456`

This password is extremely easy to guess because it is short and consists only of commonly used numbers.

**Security Level:** 🔴 Very Weak

**Recommendation:** Use a much longer and unique password.

---

### Weak Password

**Example:** `Marjani123`

This password contains letters and numbers, but it uses a predictable word followed by a simple number pattern.

**Security Level:** 🔴 Weak

**Recommendation:** Avoid common words, names, and predictable number sequences.

---

### Medium Password

**Example:** `Marjani@2025`

This password includes letters, a number, and a special character. However, it still contains a recognizable word and predictable year.

**Security Level:** 🟡 Medium

**Recommendation:** Make the password longer and more unpredictable.

---

### Strong Password

**Example:** `M@rJ@ni!_#456`

This password uses uppercase letters, lowercase letters, numbers, and multiple special characters.

**Security Level:** 🟢 Strong

**Recommendation:** Use unique passwords of this type for important accounts, preferably generated and stored using a password manager.

---

### Very Strong Password

**Example:** `T!ger$Fly_Safe_9*`

This password is longer and combines multiple character types.

**Security Level:** 🟢 Very Strong

**Recommendation:** A unique, long password or randomly generated password is preferred for real accounts.

---

## 5. Common Password Attacks

### Brute-Force Attack

A brute-force attack attempts many possible password combinations until the correct password is found.

Longer passwords increase the number of possible combinations and make exhaustive guessing more difficult.

### Dictionary Attack

A dictionary attack uses lists of common words, passwords, and predictable combinations.

Passwords based on common words or personal information are more vulnerable to this type of attack.

### Credential Stuffing

Credential stuffing involves using usernames and passwords obtained from previous data breaches to attempt access to other accounts.

Password reuse makes this attack much more effective.

---

## 6. Password Security Best Practices

The following practices should be followed:

* Use long and unique passwords.
* Use a different password for every important account.
* Avoid names, birthdays, phone numbers, and other personal information.
* Avoid common passwords and dictionary words.
* Use a password manager to generate and store strong passwords.
* Enable Multi-Factor Authentication (MFA).
* Never share passwords with other people.
* Never enter real passwords into online password-checking websites.

---

## 7. Key Findings

The evaluation shows that password security generally improves when passwords are:

* Longer
* More unique
* Less predictable
* Not based on personal information
* Resistant to common guessing patterns

Password length and uniqueness are particularly important factors in protecting accounts against automated password attacks.
