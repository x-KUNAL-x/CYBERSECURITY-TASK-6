## Create a Strong Password and Evaluate Its Strength

### 📌 Objective

The objective of this task is to understand what makes a password strong and how password complexity affects security.

In this task, multiple passwords with different levels of complexity are created and evaluated using an online password strength checker. The results are compared to understand the importance of password length, character variety, and resistance to common password attacks.

## 🔍 What Makes a Password Strong?

A strong password should generally:

* Be long and difficult to guess.
* Use a combination of uppercase and lowercase letters.
* Include numbers and special characters where appropriate.
* Avoid common words and predictable patterns.
* Avoid personal information such as names, birthdays, or phone numbers.
* Be unique for every account.
* Avoid commonly used passwords.

### Example

❌ Weak:

`Password123`

❌ Predictable:

`Kunal@123`

✅ Better approach:

Use a **long, unique passphrase or randomly generated password** that is not based on personal information.

## ⚔️ Common Password Attacks

### 1. Brute-Force Attack

In a brute-force attack, an attacker systematically tries many possible password combinations until the correct password is discovered.

Longer and more complex passwords significantly increase the number of possible combinations.

### 2. Dictionary Attack

A dictionary attack uses lists of commonly used passwords, words, phrases, and previously exposed credentials.

Passwords based on common words are particularly vulnerable to this type of attack.

### 3. Credential Stuffing

Attackers may use usernames and passwords obtained from previous data breaches to attempt access to other accounts.

This is why using the **same password across multiple accounts is dangerous**.

---

## 🛡️ Password Security Best Practices

* 🔐 Use a unique password for every important account.
* 📏 Prefer long passwords or passphrases.
* 🚫 Avoid common and predictable passwords.
* 🚫 Do not reuse passwords.
* 🔑 Consider using a reputable password manager.
* 🛡️ Enable Multi-Factor Authentication (MFA) whenever available.
* 🔄 Change compromised passwords immediately.
* ⚠️ Never share passwords with others.
* 🌐 Do not enter real passwords into online password-checking websites.

---

## 📈 Key Findings

The evaluation demonstrates that password security improves significantly when passwords become:

* Longer
* More unpredictable
* Less based on dictionary words
* Unique to individual accounts
* Resistant to common guessing patterns

Password **length and uniqueness** are especially important because they make guessing and automated attacks more difficult.
